# Campfire

Crée une application mobile moderne optimisée pour smartphone. L'écran d'accueil comporte uniquement un logo temporaire et deux gros boutons : "Créer une partie" et "Rejoindre une partie". Utilise un design sombre inspiré des jeux de rôle, avec une interface claire et épurée. Ne crée aucune logique métier pour l'instant. Prépare uniquement la navigation.
